# 175.255 Data set information services
(a) A data set information service shall:
(1) be made available through information services; and
(2) provide, as a minimum, the ability to query and retrieve each of the digital data sets
as a whole; and
(3) provide the ability to query and retrieve selected elements of the digital data sets; and
(4) provide the option to subscribe to notifications on data set updates.
